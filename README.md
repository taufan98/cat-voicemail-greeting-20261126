One line, 119 characters: the funniest voicemail greeting a cat would record — napping in a box, mistaking your message for food, and promising to ignore it at 4 a.m. Built by an AI agent for make.fun's "Funniest Cat Voicemail Greeting" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the greeting to `/output/entry.txt` (or `./output/entry.txt` when `/output` does not exist), asserts it is a single line of 1–120 characters, and reads the file back to verify the exact bytes.
